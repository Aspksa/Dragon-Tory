# История чатов

Начиная с версии 00.00.07 Дракончик Тоору хранит историю диалогов локально.

## Разделение данных

История сообщений и долговременная память — разные системы.

- история чатов: `data/chat/tooru_chat.sqlite3`;
- долговременная память: `data/memory/tooru_memory.sqlite3`.

Удаление чата удаляет только сообщения выбранного диалога. Воспоминания,
которые ранее были приняты Хранителем памяти, при этом не удаляются.

## Возможности

В разделе «Чат» доступны:

- создание нового чата;
- автоматическое название по первому сообщению;
- список прошлых диалогов;
- поиск по названию и содержимому сообщений;
- открытие истории после перезапуска Dragon Tory;
- переименование;
- удаление;
- копирование ответа;
- повтор последнего ответа;
- остановка активной генерации.

DeepSeek остаётся единственной моделью. Пользователь не выбирает проект или
модель: проектный контекст `dragon-tory` подключается автоматически вместе с
личной памятью.

## API

- `GET /v1/chats` — список и поиск;
- `POST /v1/chats` — новый чат;
- `GET /v1/chats/{chat_id}` — чат и его сообщения;
- `PATCH /v1/chats/{chat_id}` — переименование;
- `DELETE /v1/chats/{chat_id}` — удаление истории диалога;
- `POST /v1/chat` — сообщение в выбранный чат;
- `POST /v1/chat/{chat_id}/retry` — повтор последнего ответа;
- `POST /v1/chat/cancel/{request_id}` — остановка активной генерации.

# Dragon-Tory

**Дракончик Тоору — Ver 00.00.02**

Персональная AI-платформа с раздельной личной и проектной памятью,
инструментами и маршрутизацией между DeepSeek и Claude.

## Memory Engine v4

В ядре уже есть:

- жёстко разделённая личная и проектная память;
- факты, предпочтения, решения, задачи, события, эпизоды, цели и сущности;
- embeddings и постоянный векторный индекс;
- гибридный semantic + lexical recall;
- reranking по важности, достоверности, свежести и частоте использования;
- закрепление критически важной памяти;
- временная память с датой истечения;
- статусы active / archived / superseded;
- точная и семантическая защита от дублей;
- фиксация противоречий и заменённых решений;
- граф связей;
- автоматическое извлечение памяти из разговоров;
- автоматические сводки;
- история каждой ревизии;
- обучение полезности памяти через helpful/unhelpful feedback;
- автоматическое локальное обслуживание и архивирование;
- CI-тесты памяти в GitHub Actions.

Авторизация и центральная мобильная синхронизация намеренно пока не добавлены.

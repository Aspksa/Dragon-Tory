Организация документа

Данные документа

Тоору хранит техническую ДНК внутри системы, а здесь показывает рабочие данные. Автоматизация заполняет только пустые поля и не перезаписывает введённое вами.
Работа в выходной день → данные для табеля

Допуск Тоору

🤝 ИИ-договор документа

Права проверяются backend. Запрет внешнего ИИ нельзя обойти прямым вызовом API.

Где используется документ

Файл всегда остаётся в вашем «Моём диске Тори». Связь с проектом только определяет, в каком проектном контексте Тоору сможет искать и использовать документ.
Изменение ИИ-допуска не запускает скрытое чтение. Пока индексатор не обработал текущую версию, паспорт показывает статус «требуется индексация».

🔐 Сейф Тори

Шифрование особо защищённых документов
Используется AES-256-GCM. Парольная фраза не сохраняется на диске: из неё выводится ключ, который находится только в памяти до блокировки или перезапуска приложения.
Проверка…
Если парольная фраза потеряна, расшифровать защищённые документы невозможно. Dragon Tory намеренно не хранит её и не может восстановить.

# DeepSeek и Конвейер чата

Начиная с версии 00.00.06 Дракончик Тоору использует одну облачную ИИ-модель:
DeepSeek через Cloud.ru Foundation Models.

## Чат

Пользователь больше не выбирает проект или модель в интерфейсе.

Путь сообщения:

Пользователь -> личная и проектная память Dragon Tory -> DeepSeek ->
ответ -> Хранитель памяти -> Движок памяти.

Проектный контекст dragon-tory выбирается автоматически. Личная память также
добавляется в контекст без дополнительных настроек пользователя.

## Проверка важных воспоминаний

Для критически важных изменений памяти используется второй независимый проход
через тот же DeepSeek: первый запрос анализирует память, второй перепроверяет
решение. Это сохраняет защитную схему без подключения второй модели.

## Настройки

В разделе «Настройки» остаётся только Cloud.ru Key Secret для DeepSeek.
Модель и адрес API задаются самим Dragon Tory:

- API: https://foundation-models.api.cloud.ru/v1
- модель: deepseek-ai/DeepSeek-V4-Flash

Старые локальные переменные TOORU_CLAUDE_* автоматически удаляются из .env.

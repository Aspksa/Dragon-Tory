# Маршрутизатор ИИ v2 и Конвейер чата

Версия 00.00.04 добавляет два полноценных ИИ-провайдера:

- DeepSeek через Cloud.ru Foundation Models;
- Клод через официальный Anthropic Messages API.

## Автоматический выбор

В чате режим «Автоматически» оценивает сложность запроса.

Обычные короткие запросы идут в DeepSeek. Длинные запросы, длинная история,
большой контекст памяти и задачи анализа/архитектуры/рефакторинга повышают
сложность; при достаточной сложности первым выбирается Клод.

Если выбранный провайдер вернул ошибку, Маршрутизатор ИИ v2 автоматически
пробует второй доступный провайдер. В ответе чата сохраняются сведения о
выбранном провайдере, причине маршрутизации и факте резервного перехода.

## Конвейер чата

Путь одного сообщения:

Пользователь -> Контекст памяти -> Маршрутизатор ИИ v2 -> модель ->
ответ -> Хранитель памяти -> Движок памяти.

Хранитель памяти по возможности использует DeepSeek как анализатор и Клод как
проверяющего важных изменений. Если Клод не настроен, существующие защитные
правила оставляют рискованные изменения в очереди.

## Настройки

Ключи сохраняются только локально в .env и никогда не возвращаются через API.

DeepSeek:

- TOORU_DEEPSEEK_API_KEY
- TOORU_DEEPSEEK_BASE_URL
- TOORU_DEEPSEEK_MODEL

Клод:

- TOORU_CLAUDE_API_KEY
- TOORU_CLAUDE_MODEL

Обе модели можно проверить отдельными кнопками в разделе «Настройки».

# Личный помощник Тоору: документы через чат

Начиная с **Dragon Tory 00.00.26** чат является главным входом для личных
документов.

## Что происходит при загрузке

1. Пользователь прикрепляет один или несколько файлов в чате.
2. Файл сохраняется в «Мой диск Тори» с источником `chat-upload`.
3. Для чат-загрузки включается личный AI-контур `memory`:
   чтение содержимого, ответы, внешний DeepSeek и память.
4. Единый Document Intelligence извлекает текст, выполняет OCR при
   необходимости, классифицирует документ и заполняет безопасные подсказки ДНК.
5. Весь извлечённый текст сохраняется в локальном поисковом индексе по
   фрагментам.
6. Если DeepSeek настроен, все извлечённые фрагменты изучаются блоками.
   Для длинных документов промежуточные конспекты иерархически объединяются.
7. Итоговое знание проходит через Memory Intake Gateway и Guardian и попадает
   в личную долговременную память либо в очередь проверки по правилам Guardian.
8. Последующие вопросы в обычном чате автоматически получают релевантные
   фрагменты индексированных документов как недоверенный справочный контекст.

## Поддерживаемые форматы

Нативно: текстовые файлы, Markdown/JSON/YAML, HTML/XML, CSV/TSV, PDF с
текстовым слоем, DOCX, XLSX/XLSM, XLS, XLSB, PPTX, ODT/ODS/ODP, RTF,
EML, MSG и EPUB.

OCR: PNG, JPG/JPEG, TIFF, BMP, WEBP и сканированные PDF.

Старые Office: DOC, DOCM, PPT, PPTM и WPS через локальный LibreOffice.

## Локальные движки Windows

`Start.bat` автоматически устанавливает Python-библиотеки из
`pyproject.toml`. Если Tesseract OCR или LibreOffice отсутствуют, bootstrap
пытается установить их через `winget`. Ошибка установки этих внешних движков
не блокирует запуск Dragon Tory: интерфейс продолжает работать, а статус
распознавания показывает, какого движка не хватает.

## Безопасность

Содержимое документов считается недоверенными данными. Команды и инструкции,
найденные внутри документов, не должны управлять Тоору. Документный текст
проходит через Prompt Guard, а долговременная память — через Guardian.

Обычная загрузка через «Мой диск» сохраняет прежние строгие разрешения и не
получает `memory` автоматически. Автоматическое изучение включено именно для
явной загрузки пользователем через личный чат.


## Надёжность 00.00.28

Начиная с Dragon Tory 00.00.28 длинный итоговый AI-конспект документа больше
не передаётся целиком в ограниченное поле `MemorySearch.query`. Внутренние
поисковые запросы памяти автоматически сокращаются до безопасного размера,
при этом само долговременное знание сохраняется полностью.

Если документ уже был сохранён через чат, но его изучение ранее оборвалось,
в «Центре документа» доступно действие **«Повторно изучить в память»**. Новый
файл загружать не требуется: сохраняются тот же Tory Document ID и история.

### Работа в выходной день

Для служебных записок Тоору детерминированно извлекает несколько дат, включая
форматы:

- `24-25.01.2026`;
- `31.01 и 01.02.2026`;
- «21 и 22 марта 2026»;
- «31 января и 1 февраля 2026».

Даты из имени файла сравниваются с датами в формулировке о рабочих днях внутри
самого документа. Если они расходятся, документ остаётся изученным и
проиндексированным, но получает статус **«требуется проверка дат»**. До ручного
подтверждения такие даты не попадают автоматически в табель РВ и не
сохраняются как подтверждённый долговременный факт.

Ручное исправление дат имеет приоритет над повторным автоматическим анализом.

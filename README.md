# Dragon-Tory

**Дракончик Тоору — Ver 00.00.02**

Персональная AI-платформа с раздельной личной и проектной памятью,
инструментами и маршрутизацией между DeepSeek и Claude.

## Уже в ядре

- FastAPI backend;
- личная и проектная память с жёсткой изоляцией;
- типы памяти: факты, предпочтения, решения, задачи, события и правила;
- версии записей и защита от конфликтующих обновлений;
- embeddings-слой и постоянный векторный индекс;
- гибридный semantic + lexical recall и reranking;
- автоматическое выделение долговременной памяти из диалога;
- защита от точных дублей;
- фиксация противоречий и заменённых решений;
- граф связей между воспоминаниями;
- автоматические сводки памяти;
- AI Router для будущего подключения DeepSeek и Claude.

Подробности: docs/ARCHITECTURE.md и docs/MEMORY_ENGINE.md.

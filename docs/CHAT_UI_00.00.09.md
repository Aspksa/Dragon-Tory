# Чат 00.00.09

Версия 00.00.09 упрощает основной интерфейс чата.

## Поле ввода

Отдельная нижняя панель кнопок удалена. В обычном состоянии справа внутри
компоновщика показывается одна кнопка отправки. Пока DeepSeek отвечает, эта же
кнопка превращается в остановку генерации.

Переключатель памяти и режим ответа находятся внутри компоновщика и не занимают
отдельную строку управления.

## Действия у ответа

Под ответом Тоору показываются контекстные действия:

- Копировать;
- Повторить ответ — только у последнего ответа.

Поэтому отдельная постоянная кнопка «Повторить ответ» внизу больше не нужна.

## Режимы ответа

Модель остаётся только одна — DeepSeek. Пользователь выбирает не модель, а
формат ответа:

- Кратко;
- Обычно;
- Подробно;
- Код;
- Анализ.

## Удобство

- безопасное отображение Markdown;
- блоки кода с отдельной кнопкой копирования;
- черновик сохраняется отдельно для каждого чата в браузере;
- Enter отправляет сообщение, Shift+Enter добавляет строку;
- Ctrl+N создаёт новый чат;
- Ctrl+K переводит курсор в поиск по чатам;
- поле сообщения автоматически меняет высоту.

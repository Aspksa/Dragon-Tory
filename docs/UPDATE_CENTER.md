# Центр обновления

Версия 00.00.05 усиливает автоматическое обновление Dragon Tory.

## Нижний пункт «Обновление»

В левой панели в самом низу остаётся только отдельный пункт «Обновление».
Он открывает полноценный Центр обновления.

Центр показывает:

- локальную и удалённую версии;
- GitHub SHA;
- текущий этап и процент выполнения;
- живой heartbeat процесса обновления;
- предупреждение о зависшем процессе;
- список скачанных файлов;
- новые, изменённые и удалённые файлы;
- историю обновлений с русским описанием;
- резервную копию и результат автоматического отката.

## Защита от зависшего статуса

Backend хранит PID отдельного updater-процесса и проверяет его существование.
Если процесс завершился раньше времени, статус автоматически меняется на
«Ошибка обновления» и показывает последние строки журнала запуска.

Каждый этап PowerShell updater обновляет heartbeat. Если heartbeat не менялся
более трёх минут, интерфейс показывает предупреждение о зависании.

## Локальные данные

Обновление не заменяет:

- .env;
- .venv;
- data;
- runtime;
- logs;
- backups;
- .git.

История хранится в data/update/history.json, а технические журналы — в
logs/update.log и logs/update-launcher.log.

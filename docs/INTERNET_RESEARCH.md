# Интернет-поиск личного помощника Тоору

Начиная с **Dragon Tory 00.00.28** чат Тоору умеет выполнять реальный
интернет-поиск для запросов, где актуальные внешние сведения действительно
нужны.

## Когда используется интернет

Web research запускается для явных или явно актуальных запросов, например:

- «найди в интернете …»;
- «проверь на официальном сайте …»;
- актуальная цена, новости, расписание, погода;
- текущие характеристики;
- расход топлива / ГСМ автомобиля.

Обычный локальный разговор и работа с личными документами не отправляются
в интернет автоматически.

## Как проходит запрос

1. Тоору формирует поисковый запрос из текущего сообщения пользователя.
2. Поиск выполняется через публичную HTML-выдачу поисковой системы.
3. Несколько результатов могут быть открыты для получения текста страницы.
4. HTML очищается от скриптов, форм, навигации и другого служебного содержимого.
5. Весь внешний текст помечается как `UNTRUSTED_CONTENT` и проходит Prompt Guard.
6. DeepSeek получает только подготовленные фрагменты с метками `[Web N]`.
7. Ответ показывает список использованных интернет-источников.

Если интернет технически недоступен, Тоору сообщает конкретную ошибку поиска,
а не утверждает, что интернет-функций у системы вообще нет.

## Безопасность

Web research блокирует:

- localhost;
- loopback и приватные/служебные IP-адреса;
- `.local` и `.internal`;
- схемы кроме HTTP/HTTPS;
- URL с логином/паролем;
- редиректы на локальные или небезопасные адреса.

Это снижает риск SSRF и защищает локальный API Dragon Tory.

Данные с сайтов никогда не считаются системными инструкциями. Команды,
найденные внутри веб-страницы, не должны управлять Тоору или его инструментами.
